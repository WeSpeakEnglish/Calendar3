      Events JSON

      This is your events file (public holidays are kept in their own file). Save the text as a .json file and load it with Import events…. Dates: "MM-DD" repeats yearly, "YYYY-MM-DD" is a single day, "easter": -2 counts days from Easter Sunday. Types: holiday, personal, work, birthday, other.

      Public holidays file

      Choose each file once, e.g. C:\PRJ\Calendar\calendar.json and C:\PRJ\Calendar\czech-holidays.json. The calendar remembers them: every event change is saved to the events file, and both files are loaded when you open the calendar. The holidays file is only read, never changed. Your browser may ask once per visit to allow access – that's a browser security rule for local files.
